# Задача по нахождению равновесия при составлении планов производства

## Исходные данные

Дан кластер производетелей (база данных прилагается в скрипте). Каждый производетель производит номенклатуру продуктов. Продукты могут быть сырьём для других продуктов и/или направляться за пределы кластера на продажу. Есть генеральный план по выпуску продукции за пределы кластера. Каждый участник кластера составляет свой план производства в зависимости от своих потребностей (максимизация производства/прибыли) и ограничений (входное сырьё, трудовые ресурсы и т.д.). Затем эти планы нужно учесть и изменить таким образом, чтобы в сумме они давали генеральный план (всегда будут разногласия между участниками кластера, "перетягивания одеяла" и т.д.)

## Задачи

1. Предложить способы задания ограничений и целевой функции предприятия для расчёта оптимального плана для каждого участника кластера. Пока не рассматриваем сценарий "произведём сейчас побольше, в следующий период будем производить меньше и добирать продукцию со склада"
2. Предложить способы решения конфликтов между участниками кластера и изменения планов предприятий для соответствия генеральному плану

## Варианты

1. Максимизация прибыли (приоритетный)
  1. Добавить затраты на производство каждого продукта (энергия, трудовые ресурсы, финансы, ...)
  2. Добавить отпускные цены на конечные продукты, по которым будет производиться максимизация прибыли от плана и расчёт плана предприятия
2. Минимизация отклонения от генерального плана (не прорабатывался)
3. Максимимизация занятости производственных мощностей (всё равно, что производить, лишь бы цеха не останавливались; не прорабатывался)
